# 网页搜索工具

一个高效的网页搜索助手。

---

## PART A: Work

### 功能描述

- 核心能力：根据关键词搜索网页并返回结构化结果摘要

### 使用方法

- 触发方式：用户说「搜索 xxx」或「查一下 xxx」
- 输入要求：需要提供搜索关键词，可选时间范围

### 参数配置

- 结果数量：默认 5 条，范围 1-10
- 语言：默认中文，可切换英文

### 工作流程

1. 解析用户关键词
2. 调用搜索接口
3. 过滤低质量结果
4. 生成摘要列表

### 输出偏好

- 每条结果包含：标题、URL、一句话摘要
- 按相关度排序

### 经验知识库

- 搜索词过长时自动拆分
- 无结果时建议更换关键词
